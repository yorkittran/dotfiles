Write implementation plans to `.claude/plans/` within the project directory so they persist across sessions and are accessible to the team.

**Why:** The user explicitly asked to write the plan into the .claude folder of the project rather than only keeping it in the ephemeral session plan file.
**How to apply:** When creating implementation plans, write them to `.claude/plans/` in the project root in addition to (or instead of) the session plan file.
