When creating PRs, check for `.github/pull_request_template.md` in the repo and use it. Keep the summary section short (1-3 bullet points).

**Why:** User was unsatisfied with a verbose PR body and pointed to their existing template.
**How to apply:** Before creating a PR with `gh pr create`, read the repo's PR template if it exists and format the body accordingly. Don't over-describe — keep it concise.
