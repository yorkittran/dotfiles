Stop after each implementation phase so the user can create a PR for review before continuing to the next phase. Don't auto-continue into the next phase.

**Why:** The user wants incremental PRs per phase for team review.
**How to apply:** After completing all subtasks in a phase, report what was done and stop. Wait for the user to confirm before starting the next phase.
